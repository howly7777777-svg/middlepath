# 中道生活 Middle Path — GitHub Pages 網站

上傳整個 `website/` 目錄到 GitHub Pages 後，即可作為 App Store 的隱私政策與支援頁。

## 目錄結構

```
website/
  index.html          ← 語言選擇首頁
  styles.css
  zh-hans/index.html  ← 简体中文首页
  zh-hans/privacy.html
  zh-hant/index.html  ← 繁體中文首頁
  zh-hant/privacy.html
  en/index.html       ← English home
  en/privacy.html
```

## App Store Connect 建議填寫

上傳並啟用 Pages 後，將下方網址替換成你的實際網域（例如 `https://YOUR_USER.github.io/YOUR_REPO/`）：

| 欄位 | URL 範例 |
|------|----------|
| Privacy Policy URL（簡中為主可填） | `https://YOUR_USER.github.io/YOUR_REPO/zh-hans/privacy.html` |
| 或英文 | `https://YOUR_USER.github.io/YOUR_REPO/en/privacy.html` |
| EULA（Standard） | `https://www.apple.com/legal/internet-services/itunes/dev/stdeula/` |
| Support URL | `https://YOUR_USER.github.io/YOUR_REPO/` 或 `mailto:howly7777777@gmail.com` |
